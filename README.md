# tillie CLI

Release downloads for the `tillie` command-line tool — manage tillie stores, menus, orders and sales from a terminal or an AI agent.

## Install (macOS · Linux)

```sh
curl -fsSL https://tillie.club/download/cli/install.sh | sh
tillie login
```

The installer verifies each download against `SHA256SUMS` from the same release.

Releases on this repository are published automatically. The source code is maintained in a private repository, so issues and pull requests are not accepted here.
